# Proyecto-Final
Proyecto Final de la clase Introducción a la Ciencia de Datos
RENDIMIENTO ESTUDIANTIL APP

Student Performance Analyzer

Aplicación móvil para análisis del rendimiento estudiantil

Descripción • Características • Instalación • Uso • Estructura • Tecnologías

Descripción

Student Performance Analyzer es un proyecto final desarrollado en MIT App Inventor que analiza datos relacionados con los hábitos de estudio, las asistencias y el rendimiento estudiantil durante el ciclo escolar.

El proyecto emplea datos académicos para identificar tendencias, comparar variables y evaluar la relación entre los hábitos de estudio, la asistencia y el desempeño escolar.

La aplicación utiliza una base de datos relacionada con el rendimiento estudiantil y presenta los resultados mediante una interfaz móvil orientada al análisis académico.

Características

Visualización y análisis de datos

Consulta de los datos académicos registrados.

Visualización gráfica de los resultados.

Análisis de la relación entre hábitos de estudio, asistencia y rendimiento escolar.

Comparación de variables académicas.

Identificación de tendencias en los datos.

Interfaz móvil

La aplicación cuenta con diferentes procedimientos para trabajar con los datos:

Vista de Datos

Limpiar Datos

Dibujar LOBF

Predicciones

Análisis mediante gráficas

La aplicación permite representar los datos y visualizar tendencias para facilitar su interpretación.

Línea de mejor ajuste (LOBF)

Se incorpora la opción de Dibujar LOBF para representar gráficamente la tendencia de los datos.

Predicciones

La aplicación incluye un apartado de Predicciones para realizar el análisis correspondiente a partir de los datos académicos.

🔗 Conexión con Google Sheets

La información utilizada por el proyecto se encuentra vinculada a una hoja de Google Sheets, utilizada como fuente de datos para el análisis.

Instalación

Requisitos previos

Cuenta de Google.

Acceso a Google Sheets.

MIT App Inventor.

Dispositivo móvil Android para ejecutar y probar la aplicación.

Pasos

Acceder a MIT App Inventor.

Importar el proyecto de la aplicación.

Verificar la conexión con la hoja de Google Sheets.

Ejecutar la aplicación en un dispositivo compatible.

Cargar o consultar los datos académicos.

Utilizar las opciones de visualización, análisis, LOBF y predicciones.

Uso

Al iniciar la aplicación se presenta la interfaz de Rendimiento Estudiantil.

El usuario puede seleccionar el procedimiento que desea realizar:

Vista de Datos: permite consultar la información utilizada por la aplicación.

Limpiar Datos: permite trabajar con los datos antes de realizar el análisis.

Dibujar LOBF: genera la representación de la línea de mejor ajuste.

Predicciones: permite visualizar los resultados del análisis predictivo.

Las diferentes pantallas de la aplicación muestran tanto la interfaz desarrollada como los resultados obtenidos.

Este proyecto fue desarrollado como Proyecto Final para el análisis del rendimiento estudiantil. Su propósito es aplicar herramientas de desarrollo móvil y análisis de datos para estudiar información académica y facilitar su interpretación mediante una aplicación.
